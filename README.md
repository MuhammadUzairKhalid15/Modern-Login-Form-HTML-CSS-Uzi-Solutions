# Modern Login Form UI (HTML & CSS)

A clean, modern login form built with **HTML & CSS only**. Teal theme, icon boxes attached to each input, a glowing focus effect and a smooth hover on the login button. **Zero JavaScript.**

🔗 **Live Demo:** https://muhammaduzairkhalid15.github.io/Modern-Login-Form-HTML-CSS-Uzi-Solutions/
💻 **Repository:** https://muhammaduzairkhalid15.github.io/Modern-Login-Form-HTML-CSS-Uzi-Solutions/

> ⭐ If this helped you, a star on the repo means a lot!

## ✨ Features

- 🎨 Teal-themed card with a bold header
- 👤 Input fields with attached icon boxes (Boxicons)
- ✨ Focus effect: colored border and soft inner glow
- 🔘 Login button with a smooth hover transition
- 🔗 "Forgot Password?" and "Signup now" links
- 📐 Fluid card (`max-width: 440px`) centered on the page
- 🚫 No JavaScript

> Note: this is a front-end UI only. There is no backend or real authentication.

## 🔧 Built With

- **HTML5**
- **CSS3**: absolute positioning, transitions, `box-shadow`, `:focus` and `:hover` states
- **Boxicons**: icons
- **Google Fonts**: Poppins

## 💡 What I Practiced

- Placing an icon inside an input using `position: absolute` and `padding-left`
- Styling `:focus` with `border-color` and an inset `box-shadow`
- Smooth transitions on inputs and buttons
- Styling form elements with the `required` attribute and proper input types
- Structuring a form with reusable `.row` blocks
